# メモ（memos）

## 目的

家のことで思いついた一言を、X に投稿するような手軽さで書き留める。書いたメモはホームのタイムライン（[home.md](home.md)）に、ほかの記録と一緒に書いた時刻の位置で並ぶ。

## 画面

専用の画面は持たない。

- 書く: ホームの右下の追加ボタンの「メモ」（`src/features/memos/components/MemoForm.tsx`。スマホはシート、PC はダイアログ）。本文は 500 文字までのプレーンテキストで、上限を超えては打てず、欄の下に今の文字数を出す（`MemoField`）。本文を打つだけのフォームなので、追加のシートはタスクの追加と同じく開いた所からそのまま打てる（入力欄に焦点を当てる）。
- 読む・直す・消す: タイムラインの行を押して開く詳細（`MemoDetailSheet`）。書いた人と日時・本文を出し、鉛筆で本文を直し、三点リーダーから消す。直しても書いた時刻は変わらない（タイムラインの位置が動かない）。直す・消すは書いた本人だけで、ほかの人のメモは読むだけ（鉛筆も三点リーダーも出さない）。メモは書いた人の言葉なので、家族で管理する共有の記録（予定・タスク・立替・レモン）と違って本人のものとして扱う。

## データ

`memos`（[data-model.md](../data-model.md)）。本文と書いた人・書いた時刻だけを持つ。本文の規則（空でない・500 文字まで）は `shared/validation/memos.ts`。

## API（`server/features/memos/routes.ts`）

| メソッド | パス | 内容 |
|---|---|---|
| POST | `/api/memos` | 作成。`id` を指定するとその ID で作る（同じ ID の再送は二重に作らない） |
| PUT | `/api/memos/:id` | 本文を置き換える。書いた本人以外は 403 |
| DELETE | `/api/memos/:id` | 削除。書いた本人以外は 403 |

読むのはタイムライン（`GET /api/timeline`）だけなので、一覧の口は持たない。
