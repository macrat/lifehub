# メモ（memos）

## 目的

家のことで思いついた一言を、X に投稿するような手軽さで書き留める。書いたメモはホームのタイムライン（[home.md](home.md)）に、ほかの記録と一緒に書いた時刻の位置で並ぶ。

## 画面

専用の画面は持たない。

- 書く: ホームの右下の追加ボタン（`src/features/memos/components/MemoForm.tsx`。スマホはシート、PC はダイアログ）。本文は 500 文字までのプレーンテキストで、上限を超えては打てず、欄の下に今の文字数を出す（`MemoField`）。本文を打つだけのフォームなので、追加のシートを開いたときも詳細を編集に切り替えたときも、そのまま打てる（入力欄に焦点を当てる）。
- 読む・直す・消す: タイムラインの行を押して開く詳細（`MemoDetailSheet`）。書いた人と日時・本文を出し、鉛筆で本文を直し、三点リーダーから消す。直しても書いた時刻は変わらない（タイムラインの位置が動かない）。直す・消すは書いた本人だけで、ほかの人のメモは読むだけ（鉛筆も三点リーダーも出さない）。書いたメモは送信を待たずにタイムラインへ先に出す。ログイン中のユーザーがまだ手元に無いときも出し、書いた人は取り直すまで空のままにする（レモンの記録と同じ）。メモは書いた人の言葉なので、家族で管理する共有の記録（予定・タスク・立替・レモン）と違って本人のものとして扱う。

## データ

`memos`（[data-model.md](../data-model.md)）。本文と書いた人・書いた時刻だけを持つ。本文の規則（空でない・500 文字まで）は `shared/validation/memos.ts`。

## API（`server/features/memos/routes.ts`）

| 手続き | 種類 | 内容 |
|---|---|---|
| `memos.create` | 書き込み | 作成。`id` を指定するとその ID で作る（同じ ID の再送は二重に作らない） |
| `memos.update` | 書き込み | 本文を置き換える（入力はメモの `id` と本文）。書いた本人以外は拒む（`FORBIDDEN`） |
| `memos.delete` | 書き込み | 削除（入力は `id`）。書いた本人以外は拒む（`FORBIDDEN`） |

読むのはタイムライン（`timeline.get`）だけなので、一覧の手続きは持たない。

## MCP ツール

`add_memo`, `update_memo`。読むのは `read_timeline`、消すのは `delete_entry`（[mcp.md](mcp.md)）。
